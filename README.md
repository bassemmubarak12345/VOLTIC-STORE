# VOLTIC Fragrances | عطور رجالية فاخرة

متجر إلكتروني فاخر متخصص في أرقى وأفخم العطور الرجالية المصممة بعناية فائقة لتعكس الهيبة والجاذبية العصرية.

---

## 🌟 مميزات المتجر
- **تصميم عصري ملكي:** واجهة مستخدم فاخرة باللون الأسود والذهبي متناسقة مع أفخم دور العطور.
- **تصفيف وتصنيفات متنوعة:** تصنيف العطور بحسب الفصول والمناسبات (عطور صيفية، شتوية، مناسبات خاصة، وعطور رياضية).
- **محرك بحث ذكي كامل الشاشة:** بحث فوري وسلس عن أسماء العطور والمكونات والنوتات العطرية.
- **سلة مشتريات تفاعلية:** حساب تلقائي للشحن والخصومات مع دعم كوبونات التخفيض ونظام هدايا تفاعلي.
- **نظام الطلب السريع:** إتمام الطلب ومتابعة الشحنات بسهولة وسرعة.

---

## 🚀 كيفية التشغيل محلياً (Run Locally)

### المتطلبات الأساسية
- مثبت **Node.js** (الإصدار 18 أو أحدث)
- مدير الحزم **npm**

### خطوات التثبيت والتشغيل
```bash
# 1. تثبيت الاعتماديات والمكتبات
npm install

# 2. تشغيل السيرفر المحلي للمعاينة
npm run dev

# 3. بناء نسخة الإنتاج النهائية
npm run build
```
